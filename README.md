# Control de Equipo de Fútbol 🎯

**Aplicación web moderna para gestionar equipos de fútbol con almacenamiento permanente de datos.**

## ✨ Características Principales

- 📱 **Diseño Moderno y Responsivo** - Funciona en cualquier dispositivo
- 💾 **Almacenamiento Permanente** - Usa localStorage (sin servidor)
- 👥 **Gestión de Jugadoras** - Agregar, editar, eliminar jugadoras
- 📅 **Calendario de Eventos** - Partidos y entrenamientos
- ✅ **Control de Asistencia** - Registro por fecha
- ⚖️ **Control de Peso** - IMC automático
- 📊 **RPE (Esfuerzo Percibido)** - Escala 1-10
- 📥 **Exportar/Importar** - Descarga y carga de datos en JSON
- 📊 **Exportar a CSV** - Compatible con Excel

## 🚀 Cómo Usar

1. Abre la aplicación en tu navegador
2. Crea jugadoras en la sección "Jugadoras"
3. Agrega eventos en "Calendario"
4. Registra asistencia, peso y RPE
5. Los datos se guardan automáticamente

## 📊 Datos de Almacenamiento

Los datos se almacenan localmente en el navegador usando **localStorage**. Esto significa:

- ✅ No necesitas servidor
- ✅ Tu privacidad está garantizada
- ✅ Los datos persisten entre sesiones
- ✅ Puedes descargar un backup en JSON

## 🔧 Exportar/Importar Datos

### Descargar Backup
1. Ve al Dashboard
2. Haz clic en "Descargar Datos"
3. Se descargará un archivo JSON con todos tus datos

### Cargar Backup
1. Ve al Dashboard
2. Haz clic en "Cargar Datos"
3. Selecciona el archivo JSON que descargaste
4. Los datos se restaurarán automáticamente

## 📱 Secciones Disponibles

| Sección | Descripción |
|---------|-------------|
| **Dashboard** | Panel principal con estadísticas |
| **Jugadoras** | Gestión de perfil de jugadoras |
| **Calendario** | Partidos y entrenamientos |
| **Asistencia** | Registro de asistencia |
| **Peso** | Seguimiento de peso e IMC |
| **RPE** | Escala de esfuerzo percibido |
